# pn-policy-analyzer
A coverability analysis tool for Petri nets, used here to analyze access control policies. <tt>pns/</tt> contains the Petri nets implementing the policies and <tt>demos.py</tt> contains analyses of various aspects of them. <tt>km.py</tt> contains the code for the actual tool.

Note: This was written as part of my gradution project from the Istanbul Technical University Department of Computer Engineering. Advisor: Asst. Prof. Dr. Mehmet Tahir Sandıkkaya.
